# Getting Help

## Start here

- Read the README and the relevant documentation in `docs/`.
- Run `taskagentrelay doctor` when diagnosing a local setup.
- Search existing issues before opening a new one.

## Where to ask

- Reproducible bug → Bug Report issue.
- Feature idea → Feature Request issue.
- Design question or usage question → Question/Discussion issue.
- Code contribution → Pull Request.
- Security vulnerability → `SECURITY.md` (do not post sensitive details publicly).

TaskAgentRelay is maintained on a best-effort basis during early development. A response or merge is not guaranteed for every request, and roadmap decisions are made based on project scope and maintainability.
